Sales Dashboard | Power BI
Project Overview
The Sales Dashboard is an interactive business intelligence report built in Microsoft Power BI. It presents sales performance using KPI cards and charts, with slicers that allow users to explore the results by region, product category, and sales channel.

The Power BI report file is: Sales dashboard (PowerBI).pbix.
Dashboard KPIs
The report includes four KPI cards:
- Total Sales — overall sales amount.
- Total Profit — overall profit.
- Total Orders — number of orders.
- Average Rating — average customer rating.
Visualizations Used
The report's first page contains these visuals:
Visual	Analysis
Clustered Bar Chart	Total Sales by Category
Column Chart	Total Sales by Sales Channel
Donut Chart	Total Orders by Customer Type
Clustered Column Chart	Total Sales by Region
Line Chart	Total Sales by Month


Filters / Slicers
Users can filter the report by:
- Region
- Category
- Sales Channel
These slicers help compare performance across different business segments.
Data Fields and Measures
The report references a Sales table and includes fields such as:
- Category
- Sales Channel
- Customer Type
- Region
- Order Date
Measures referenced in the report:
- Total Sales
- Total Profit
- Total Orders
- Avg Rating
Tools and Technologies
- Microsoft Power BI Desktop
- DAX measures
- Power BI visuals and slicers
How to Open the Project
1. Download Sales dashboard (PowerBI).pbix from this repository.
2. Open Microsoft Power BI Desktop.
3. Select File → Open.
4. Choose the downloaded .pbix file.
5. Use the slicers to explore sales performance.
